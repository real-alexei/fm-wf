Fimex — B2B-платформа для закупки и продажи техники из Дубая. Мы разобрали production-бандлы, мобильный трафик и публичные страницы и собрали кликабельный прототип всех приложений: админ-панели, портала поставщика, iOS-приложения и публичного сайта. Все данные в прототипе — вымышленные, структура и подписи — из реального продукта.

С чего начать

Сценарии для коллеги

  • Понять бизнес-модель — публичный сайт → портал поставщика → iOS-приложение покупателя.
  • Увидеть операционку — админка: «Продажи» → таб «Закупки» → заказ → упаковочный лист и IMEI.
  • Оценить глубину — настройки: характеристики, карго-матрица, наценки, статусы доставки.
  • Проверить находки — страница «Как это выяснено»: хосты, API, публичные каналы.

Технически

  • Чистый HTML/CSS/JS без сборки и зависимостей — открывается двойным кликом или с GitHub Pages.
  • Данные общие для всех страниц (assets/demo-data.js): один товар, заказ и клиент выглядят одинаково везде.
  • Экраны переключаются по hash-ссылкам: admin.html#preorder, ios.html#pricelist.
  • Ссылки для публикации и структура проекта — в README.md.
  • Разделение «подтверждено / выведено / добавлено» и список наших дополнений — на странице «Провенанс».
